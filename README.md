# Phigros 难度定数预测系统 (Phigros Chart Constant Estimator)

基于 **Gradient Boosting 残差 + 手工 Boost 叠加 + 类型规则 + 双重校准** 的 Phigros 谱面定数(Chart Constant)预测器。

**设计原则**:官谱定数为唯一权威基准;上架社区定数为第二参考;未上架谱仅用于趋势验证。模型只在 982 张官谱上训练,所有社区数据只进入校准层,不进入模型权重。

---

## 统计口径(最终版 v12.15)

| 指标 | 数值 |
|---|---|
| 训练数据 | 官谱 982 张(全纯官谱,无任何社区数据) |
| 官谱整体偏差(bias) | **+0.0000**(n=982) |
| 上架社区谱 MAE | **0.373**(非整数定数、排除乱标 err≥2 后 n=422) |
| 上架社区谱 Spearman ρ | **0.882** |
| 人工锚点谱(双指/多指,约 20 张) | 绝大多数误差在 ±0.28 内 |

分段 MAE(上架社区谱):14.5~15.5 **0.30** / 15.5~16.5 **0.37** / 16.5+ **0.39** / 11~13.5 **0.75**(低段样本少且社区定数最乱,误差较大)

## 预测原理

    谱面JSON → 统一解析(官谱/RPE/PE) → 363维特征提取 → GB残差基线(level one-hot)
            → Boost叠加(条件缩放) → 类型规则(①~⑪) → 手工校准表 → 社区校准层 → 最终定数

| 模块 | 说明 |
|---|---|
| **GB 残差** | 363 特征 + 3 类 level(EZ/HD/IN_AT),纯官谱训练,低段加权 |
| **Boost 叠加** | ~50 个手工权重特征(密度/配置/耐力/读谱/位移),excess 指数 0.70,条件缩放区分双指/多指谱 |
| **类型规则** | 11 条预测时规则(双指物量/切换多指/表演压制/暴力键盘抬升等),全部为**类型级**规则,无逐谱特判 |
| **手工校准表** | 7 段,由坐标下降优化器在「社区 MAE + 锚点硬约束」联合目标上自动调参(非手调) |
| **社区校准层** | 0.5 档分段对齐社区非整数定数(排除乱标);17+ 段半对齐(社区定数膨胀);16~17 段豁免(社区系统性低标,以人工锚点为准) |
| **密度域对齐** | 自制谱 IN 段密度特征向官谱分布对齐 |
| **isFake 过滤** | RPE 假音符(isFake=1)已正确剔除,不计入物量/密度 |

### 谱面格式支持

| 格式 | 说明 |
|---|---|
| 官谱/Standard | 标准 Phigros JSON(formatVersion:3) |
| RPE | PhiEdit 导出(含 isFake 过滤、eventLayers 变速合并、速度/4.5 归一化) |
| PE 文本 | PhiEditer 遗留(时间单位=拍×32,cv/10 归一化) |

## 我们做过什么(方法论记录)

1. **特征审计**:对全部特征计算与谱面解析做了逐项彻查,修复了 30+ 处 bug(窗口密度单位、拍-秒换算、判定线位移量纲、RPE 速度归一化、PE 坐标域等),并对照官方渲染实现(PhiChartRender/rephiedit)逐条验证换算公式。
2. **类型规则**:双指/多指/表演/键盘等谱型的偏差全部用**特征阈值的类型级规则**修正,拒绝逐谱特判(会失去泛化能力)。
3. **全局联合调参(B 计划)**:所有规则力度参数化后,用坐标下降在「社区 MAE + 锚点硬约束」联合目标上自动搜索,替代串行手调(工具:tools/opt_rules_b.py)。
4. **玩家行为数据验证(A 计划,探索性)**:抓取 phira 游玩记录做 Bradley-Terry 排序,验证了"19+ 段虚高、变速读谱地狱被低估"等结论,但发现推分选择偏差问题后暂缓,未进入生产管线。
5. **社区蒸馏/伪标签/混合训练**:全部试验过,因社区标签噪声和官谱偏差漂移被否决,最终采用"官谱模型 + 社区校准层"的可逆架构。

## 已知局限(诚实声明)

Phigros 与 4k 下落式音游有本质差异,难度无法被完全量化:

- **表演 ≠ 难度**:判定线旋转/位移/演出密集的谱,特征会系统性虚高,只能靠规则压制,无法精确区分"演出"与"真位移"。
- **读谱/变速**:变速读谱地狱型谱(如 Hello (BPM) 2023)被玩家行为数据证明被低估,但这类谱数量太少,且玩家存在推分选择偏差,难以系统建模。
- **个人差**:多指谱对手型/设备敏感,双指谱对底力敏感,同一张谱不同玩家体感差异可达 0.5 以上。社区定数本身也是"共识"而非物理量,16~17 段存在系统性低标、17.5+ 段存在膨胀。
- **高定数段(17+)**:上架样本仅 33 张、官谱 17+ 仅数十张,外推能力有限。
- **低定数段(11~13.5)**:社区定数噪声最大、样本最少,MAE 0.75 明显高于中段;官方谱该段请直接参考 EZ/HD 官谱模型。
- **谱面解析**:未收录的特殊格式(愚人节谱、特殊事件)可能解析失败,约 7/5901 的残片文件无法解析。

我们尝试了特征工程、规则调参、全局优化、玩家行为数据、蒸馏等方法,当前统计(官谱 bias 0.0000 / 社区 MAE 0.373 / 锚点 ±0.28)是纯官谱监督下能达到的较优平衡。剩下的偏差是 Phigros 这种"无轨判定线"玩法的固有噪声,难以进一步消除。
