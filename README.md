# Phigros 难度定数预测系统 (Phigros Chart Constant Estimator)

基于 **Gradient Boosting 残差 + 手工 Boost 叠加** 的 Phigros 谱面定数(Chart Constant)预测器。

**设计原则**:官谱定数为权威基准;社区共识定数(上架谱 + 17+ 共识表)为第二参考。v13 起模型在官谱 982 张 + 社区共识 17+ 定数表上联合重训,预测端回到最原始的 GB+Boost(无类型规则、无校准表)。

## 预测原理

    谱面JSON → 统一解析(官谱/RPE/PE) → 特征提取(~375维) → GB残差基线(level one-hot)
            → Boost叠加(纯手工权重, 无条件缩放) → 最终定数

v13 预测端**无任何规则与校准**:GB 学习官谱与社区共识表,Boost 提供可解释的强度叠加。

| 模块 | 说明 |
|---|---|
| **GB 残差** | 官谱982 + 社区共识17+表237联合训练,3 类 level(EZ/HD/IN_AT),低段加权,17+ 表样本权重 ×2 |
| **Boost 叠加** | ~56 个手工权重特征(密度/配置/耐力/读谱/位移),excess 指数 0.70 |
| **v13 特征** | 非定轨密度(简单 4k 堆料折扣)/ 配置贫瘠度复合(stair×trill、stair×lock)/ **手速负载 speed_load**(分音数×BPM = 音符/分钟真实手速,幂 1.5 加权,均值/p90/峰值) |
| **多指特征进 GB** | mf3/mf4/wmf/和弦交替等重新进入 GB(社区共识表提供 17+ 分布) |
| **密度域对齐** | 自制谱 IN 段密度特征向官谱分布对齐 |
| **isFake 过滤** | RPE 假音符(isFake=1)已正确剔除,不计入物量/密度 |

### 谱面格式支持

| 格式 | 说明 |
|---|---|
| 官谱/Standard | 标准 Phigros JSON(formatVersion:3) |
| RPE | PhiEdit 导出(含 isFake 过滤、eventLayers 变速合并、速度/4.5 归一化) |

## 我们做过什么(方法论记录)

1. **特征审计**:对全部特征计算与谱面解析做了逐项彻查,修复了 30+ 处 bug(窗口密度单位、拍-秒换算、判定线位移量纲、RPE 速度归一化、PE 坐标域等),并对照官方渲染实现(PhiChartRender/rephiedit)逐条验证换算公式。
2. **类型规则(v12 及以前)**:双指/多指/表演/键盘等谱型偏差曾用特征阈值规则修正;v13 用社区共识 17+ 表重训替代规则,全部规则与校准层已暂停(V13_MODE 开关保留)。
3. **全局联合调参(B 计划)**:规则力度参数化 + 坐标下降在「社区 MAE + 锚点硬约束」联合目标上自动搜索(工具:tools/opt_rules_b.py)。
4. **玩家行为数据验证(A 计划,探索性)**:抓取 phira 游玩记录做 Bradley-Terry 排序,验证了"19+ 段虚高、变速读谱地狱被低估"等结论,因推分选择偏差暂缓,未进入生产管线。
5. **社区蒸馏/伪标签/混合训练**:全部试验过,因社区标签噪声被否决;最终采用"官谱+社区共识表联合训练"的原始架构。

## 已知局限(诚实声明)

Phigros 与 4k 下落式音游有本质差异,难度无法被完全量化:

- **耐力是乘性难度**:对实力超过配置的玩家,长谱耐力几乎无成本(简单 4k 长谱体感不难);v13 仅能以特征近似此效应,Σvreka 类"简单 4k 撑密度"的谱仍会高估(约 +1)。
- **手速与密度的共线**:手速负载与有效密度高度相关,GB 树模型倾向只用后者,19.1 档谱(Aegleseeker 类)仍有约 -0.4 的欠定价。
- **表演 ≠ 难度**:判定线旋转/位移/演出密集的谱特征会虚高,无规则下无法精确压制。
- **个人差**:多指谱对手型/设备敏感,双指谱对底力敏感,同一张谱不同玩家体感差异可达 0.5 以上。社区定数本身是"共识"而非物理量。
- **无规则代价**:v13 暂停规则后,17 以下人工锚点(Bonus Time/おぎゃり等)偏离 ±0.3~0.6,上架社区谱 15.5~16.5 段 MAE 0.46 略高于 v12 规则版。
- **低定数段(11~13.5)**:社区定数噪声最大、样本最少;官方谱该段请直接参考 EZ/HD 官谱模型。
- **谱面解析**:残片文件(仅 bpm/effects 无音符)与个别特殊格式无法解析,约 20/6000 比例。

我们尝试了特征工程、类型规则、全局优化、玩家行为数据、蒸馏等方法。v13 的"官谱+社区共识表原始重训"是目前较优平衡:官谱 bias 0 / 上架 MAE 0.39 / 17+ 共识表留出 0.29。剩下的偏差是 Phigros 这种"无轨判定线"玩法的固有噪声,难以进一步消除。
