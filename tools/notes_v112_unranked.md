**系统性偏移（约 35-52% 的未上架谱超官谱 16+ P90）**，按偏移强度排序：
1. **密度类**：above_avg_density_mean（P90 高出官谱 35%）、real_core_notes_per_second、eff_avg_tps_1s——未上架谱的"高潮段密度"普遍压过官谱 16+ 谱面。
2. **多押类**：multi_finger_3plus_events 的 P90=113 是官谱 16-17 段 P90（42）的 **2.7 倍**——高难自制谱普遍用多押撑密度；未上架谱多指(mf3>=30)占 **44.7%**（427/956），远高于上架谱 16+ 的 28%。
3. **读谱/规模类**：tempo_change_count、total_notes、movement_per_second、duration_sec——未上架谱整体"更长更密更花"。

多指/双指预测对比：多指谱 pred 均值 16.94 vs 双指谱 16.32（差 0.62）——模型仍给多指堆料谱更高分（条件boost mf3 衰减 0.50/0.70 只部分抑制）；而社区定数 16-18 压缩带对多指堆料更保守。

## 四、结论与对 v112 的启示

1. **未上架谱是"特征域偏移的极端样本库"**：密度/多押/读谱量约 35-52% 超官谱 16+ P90。它是检验"特征公式修正是否抑制 OOD 外推"的理想测试集——任何新公式应能让 Duplicity Shade 这类 dens 31/mf3 908 的堆料谱从 20.3 回落，同时不误伤官谱域内谱。
2. **多指堆料在未上架谱中占比 44.7%**（t1 上架谱中高估主源反而是双指 18/20）：说明多指堆料是未上架谱的主流风格，t2 的"密度虚高修正"（eff_density_ratio 等）应优先作用于高密度多指谱。
3. **社区定数 16-18 压缩带不可作为未上架谱的权威**：bias 从 16.5-17 段 +0.106 翻转到 17.5-18 段 -0.213，社区 17+ 虚高明显；预测分布（P90=17.63）反而比社区定数（P90=17.4）更接近官谱域结构。
4. **~5% 的 >18 外推**：无需 cap（v112 原则不加 cap），但可评估特征公式修正后的外推回落幅度。
5. speed_volatility 存在 10^4~10^5 量级 OOD 值（未上架 P99=100912 vs 官谱 P90=1754），为特征计算层面异常放大信号，建议独立排查（非偏差主因，与 t1 结论一致）。
