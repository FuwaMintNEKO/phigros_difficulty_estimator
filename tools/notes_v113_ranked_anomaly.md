## 高估组（72 张）：11-15 段双指谱系统偏高

**特征模式**：89%（64/72）是双指谱（mf3<=5）；特征值（dens 8.7 / eff 6.6 / nps 6.3 / notes 1212）仅比全体略高，**特征不极端**。

典型：Ocean Blue（社区11.1→预测12.88）、Saintelmo（15.0→16.57）、強風オールバック（13.0→14.57）、IMPACT（15.0→16.57）。

**解读**：这些谱的特征在官谱标尺下对应 13-15 段，但社区只给了 11-13。两种可能：
1. 社区对 11-14 段定数偏低（与 16+ 段社区偏高方向相反）
2. 模型对自制谱 11-14 段特征域外推偏高（官谱 11-13 段 OOF bias=-0.25 是低估，自制谱却高估 → domain gap）

## 低估组（55 张）：特征不足谱（社区定数虚高为主）

**特征模式**：dens 6.3（全体 8.1）/ eff 4.8 / nps 4.1 / notes 867——**全面低于官谱同段 P25**。

典型：甜甜饕餮糖糖（社区13.0→预测10.02）、Grown-up Paradise（12.8→9.95）、寄明月（13.1→10.53）、3rd Avenue（15.0→12.95）。

**解读**：模型按官谱标尺"说实话"——社区对这些低特征谱的定数虚高。**模型未必错**（t1 同结论）。特殊子类：魔理沙（16.5→13.8，4001 notes 但 70% drag、nps 1.2）——超长 drag 铺底谱，drag 特征权重低的系统性盲区。

## 改进方向（候选）

1. **低段校准**：校准表现在只有 14-17 段。若社区 11-14 段定数被认可（用户视角），可加 (11,14,-0.5~-0.8) 校准；若以官谱标尺为准则不改（模型可能在"说实话"）。需用户定夺。
2. **drag 谱盲区**：drag_ratio>0.5 的长谱（魔理沙类）系统性低估——需评估 drag 类特征（官谱 drag 谱也存在，需保官谱不失真）。
3. **低估组特征不足谱**：多数为社区虚高，记录不追（模型正确）。

## 高估组根源确认（补充分析）

**高估谱的特征密度在官谱 11-14 段 P90+**：高估组 dens P75=7.14 ≈ 官谱 11-14 段 P90（7.15），接近官谱 14-15.5 段水平。

例证：Dream of Memories（社区 13.0）dens 5.7 → 官谱 11-14 段超 98%、14-15.5 段超 79%；Ocean Blue（社区 11.1）dens 5.0 → 超 94%/44%。

**结论：模型按官谱标尺"说实话"，社区 11-14 段定数相对官谱标尺偏低 0.5~1.0**（与 16+ 段社区偏高方向相反）。改不改取决于用户目标：
- 以官谱为准 → 不改（模型高估是"正确"的）
- 贴合社区 → 加低段校准 (11,14,-0.5~-0.8)
