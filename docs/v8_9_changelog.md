## v8.9 训练完成 (2026-06-06)

### 架构变更

**从 v8.5 的 "GB基线 + Boost修正" 双模块架构 → v8.9 的 "纯GB直接预测" 架构**

经过 v8.6~v8.8 多轮迭代对比，最终确定纯GB模型最优：

| 版本 | 架构 | 测试MAE | 问题 |
|:---|:---|:---:|:---|
| v8.5 | GB基线 + Boost修正 | 0.341 | Boost与GB重复计算，手工系数难调 |
| v8.6 | GB基线 + Boost修正(优化) | **0.0001** | 过拟合，数据泄露 |
| v8.7 | GB主导 + Boost条件修正 | 0.3427 | Boost贡献50-80%，GB退化 |
| v8.7b | 纯GB (无Boost) | 0.3427 | 与v8.7持平 |
| v8.8 | Ridge + Boost校正 | 0.3502 | 线性模型表达力不足 |
| v8.9 | **GB + Boost作为特征 + 网格搜索** | **0.3335** | Boost重要性排名220/220，几乎无用 |
| v8.10 | 纯GB (无Boost) + 最优超参 | 0.3408 | 验证：Boost特征贡献可忽略 |

### 关键结论

1. **Boost特征对GB模型无增益**：v8.9中Boost重要性排名220/220（共220个特征），贡献仅0.0005
2. **GB已能自动学习所有交互模式**：170个特征×300棵树×深度3已足够捕获非线性关系
3. **网格搜索找到最优超参数**：`n_estimators=300, max_depth=3, lr=0.05, min_samples_leaf=3, subsample=0.8`
4. **v8.9 测试MAE=0.3335** 是目前所有版本中最好的
